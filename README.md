# Basetaa ERP

A Middle East-focused ERP SaaS — simpler than Odoo, built for how MENA businesses work.

## Tech Stack
- **Backend:** Odoo Community 18
- **Frontend:** Next.js + TypeScript + @carbon/react
- **Database:** PostgreSQL
- **Hosting:** VPS (Docker Compose + GitHub Actions CI/CD)
