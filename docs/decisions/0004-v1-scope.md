# ADR-0004: Version 1 Scope

**Date:** 2026-08-02
**Status:** Accepted

## Decision
V1 includes: Accounting core (full), Inventory (full), Purchase (full), Sales (full), CRM (basic), Reports & Dashboards, AI Document Recognition, E-Invoicing, Multi-company, Multi-currency, Cheques, WHT, Expenses/Petty Cash, Recurring, Intercompany, Custom Fields, PWA, REST API.

V1 excludes: HR/Payroll, Fixed Assets, Budgeting (full), POS, Hijri, Project module (full), Cost Center allocations, Native apps, Supplier portal, Email-to-document, Bank API, Consolidation.

## Consequences
- V1 is ambitious but focused on operational finance.
- Deferred items have clear roadmap placeholders.
